# Level-0-async

Proof-of-concept for an asynchronous, self-paced learning experience — Leland branding, one screen at a time, with progress saved locally so a learner can leave and resume.

This repo now covers all 12 modules of AI Builder Foundations (Level 0), built from the `async-lesson-0` skill's template: each is a single self-contained HTML page, 8 screens (Welcome, Concept, Demo, Quiz, Setup, Prompt, Stretch, Wrap up), with an animated concept illustration, an interactive demo, a one-question knowledge check, and a guided build with real copyable prompts.

This is a standalone prototype, not connected to the production course platform (`leland-courses`).

Live preview: served via GitHub Pages from this repo's `main` branch.
