# Level-0-async

Proof-of-concept for an asynchronous, self-paced learning experience — Leland branding, one screen at a time, with progress saved locally so a learner can leave and resume.

Content is a trimmed version of the AI Builder Foundations "Introduction to AI Tools" lesson: one concept (how LLMs predict text, with an animated illustration and an interactive next-word demo), a knowledge check, and a guided build (write a document with AI using a real, copyable prompt), including an animated walkthrough of exactly what to do.

This is a standalone prototype, not connected to the production course platform (`leland-courses`).

Live preview: served via GitHub Pages from this repo's `main` branch.
