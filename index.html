Concept

How large language models work

It predicts the next word. It doesn't look anything up.

It's trained on huge amounts of text, from books and articles to code and conversations, and has learned which words tend to follow which closely enough to write code, draft emails, and answer real questions.

  • Each new conversation starts fresh. Without memory, it won't recall your other chats.
  • It can be wrong. It predicts what sounds right, not what's actually true.
  • Specific prompts help. Every word you write shapes the prediction.

Build 1 · Setup

Open your tool, pick a topic

Open claude.ai, chatgpt.com, or gemini.google.com in a new tab. You'll use it on the next few screens.

Then pick a topic you know something about: your job, a hobby, a project you're working on. Stuck? Try "habits for good sleep" or "elements of a good workout routine."

Copy this prompt into your AI tool, replacing the placeholder with your topic:

Write a one-page summary document about [your topic]. Include a brief intro, 3-4 key points with explanations, and a short conclusion. Format it cleanly with headers.
Why this prompt works

Specifying format (headers, length, structure) gives the AI a clear target. Without it, the AI picks a format for you, which sometimes works but is usually less useful than asking for exactly what you want.

You should see a box with a file type and a download button. Read through it. What sounds good? What sounds AI-generated? You can ask the AI to improve anything before downloading.

This document came from the same prediction process as the demo you tried earlier. It might get a fact, name, or number wrong, so double-check anything you'd actually rely on.

🔧 Troubleshooting: the file won't download or open correctly

The AI may have generated content but didn't create an actual file. If there's no download button, ask: "Can you give me a downloadable .docx file?" If your free plan blocks file exports, copy the content and paste it manually into Google Docs instead.

Build 1 · Stretch

Go further: spreadsheet and slides

In the same chat, you can push the same topic into two more formats. This is optional, but it's where you'll see AI's range.

⚡ Spreadsheet prompt 
Use this one-pager to create a downloadable spreadsheet that pulls insights from this doc and organizes it as structured data. Include column headers and 5 example rows of realistic data.
⚡ Presentation prompt 
Create a 5-slide presentation on this topic. First show a slide preview (title + 3 bullets per slide) and confirm with me that it is the format and content I want, then generate a downloadable .pptx file with a professional design.
