Concept

Claude, ChatGPT, or Gemini

All three can chat, write, and answer questions. Each one is just better at different things.

Anthropic, OpenAI, and Google each ship a version of the same basic idea. The differences show up in what each one is best at and where it fits into the rest of your day.

The short version

|
  • Claude (Anthropic): generally strong at long, careful writing and reasoning through nuanced questions
  • ChatGPT (OpenAI): the largest ecosystem, with the most plugins, custom GPTs, and third-party tools built around it
  • Gemini (Google): built into Gmail, Docs, and Search, so it shows up right where you already work if you're on Google

Build · Setup

Pick a tool

Claude is a solid default if you're not sure which to start with. Any of the three works fine for this course. Pick one and move to the next step.

Build · First message

Create your account, then say hello

Go to your chosen tool and create a free account.

  • Go to claude.ai, chatgpt.com, or gemini.google.com, whichever you picked
  • Click Sign up
  • Use your email, or continue with your Google account
  • Verify your email if it asks you to
  • You're in

Why start here

A broad, open question gets you a quick overview of what the tool can actually do, before you have a specific task in mind. You'll get a more useful, specific prompt later in this course.

Read the reply. That's it. No need to check it for accuracy yet, just see how it responds.

🔧 Troubleshooting: it's asking for a phone number

Some tools ask for phone verification for security. It's optional on some, required on others. If you'd rather not share a number, try one of the other two tools instead.
